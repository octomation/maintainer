# v0.1.0 — Find your rhythm

Maintainer v0.1.0 helps you see your open source contribution pace and choose where to focus next. The GitHub calendar becomes a planning view in your terminal, with two smaller helpers for project upkeep.

## See the pace, choose the next session

Provide a GitHub token for your own account, then look at recent weeks and ask for a candidate day:

```sh
export GITHUB_TOKEN=your_token
maintainer github contribution lookup now/-3
maintainer github contribution suggest --target 25 now/-3
```

`lookup` shows recent weeks together. `suggest` marks a candidate with `*` and reports its current count beside the target; it does not make a commit or reserve time. The exact suggested time can vary. The calendar comes from GitHub's GraphQL API, so a token is required even for public profiles.

## Look back when you need to

`histogram 2026-09` shows the distribution of active days. `snapshot 2026 > before.json` saves counts, and `diff before.json 2026` highlights added activity since that baseline. These are useful for review; the [contribution guide](/contributions/) explains their inputs and limitations.

## Two helpers for project upkeep

- `maintainer go vanity build` keeps a branded Go import space, such as `go.octolab.org`, easy to serve from static hosting. [See a manifest example](/vanity/).
- `maintainer makefile build release.mk` composes focused build fragments into one shareable Makefile. [See the build guide](/makefiles/).

## Install and scope

Get the matching macOS or Linux archive (amd64 or arm64) from [GitHub Releases](https://github.com/octomation/maintainer/releases), install the Homebrew Cask, or follow the [source installation steps](/quickstart/).

Contribution commands read the token owner's calendar. They do not edit a repository or create contributions. A `lookup` needs an explicit `/N`, `/+N`, or `/-N` span in this version. `diff` currently wraps decreases to large positive values, so check the saved JSON for decreases. The vanity and Makefile commands generate local files; publishing those files is up to you.
