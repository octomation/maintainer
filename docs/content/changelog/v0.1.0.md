# v0.1.0 — Find your rhythm

Maintainer v0.1.0 is the first stable release. It turns your GitHub contribution calendar into a planning view in your terminal, with two smaller helpers for project upkeep.

## See the pace, choose the next session

Provide a GitHub token for your own account, then look at recent weeks and ask for a moment to date your next commit:

```sh
export GITHUB_TOKEN=your_token
maintainer github contribution lookup
git commit --date="$(maintainer github contribution suggest --target 25 git/3)"
```

`lookup` works without arguments: it shows the week of your latest commit and the one before. `suggest` never dates a commit in the future: it answers with a moment between the anchor and now, or fails. `diff` shows every change, decreases included. The [contribution guide](/contributions/) covers the date grammar, targets, and snapshots.

## What the contribution commands do

- `lookup` and `suggest` accept an empty date, a year, a month, or a day, with or without a week span; a period in the future is an error.
- `suggest` answers within [anchor, now] and the 05:00–19:00 UTC schedule, or fails with a non-zero exit code; its stdout is only the timestamp.
- `diff` prints a row per changed day with before, after, and a signed difference, and notes days only one side covers.
- Tables number weeks from the one that contains January 1 and end with a `distribution{…}` footer of the shown days by count.
- The calendar is read through GitHub's GraphQL API. Every command has `--help` with a description, grammar, and examples.
- Without a token, a command that needs GitHub fails before any request and names `GITHUB_TOKEN` and `--token`; `diff` of two files needs no token.

## Two helpers for project upkeep

- `maintainer go vanity build` keeps a branded Go import space, such as `go.octolab.org`, easy to serve from static hosting. [See a manifest example](/vanity/).
- `maintainer makefile build release.mk` composes focused build fragments into one shareable Makefile. [See the build guide](/makefiles/).

## Install

`brew install --cask octolab/tap/maintainer`, the install script, `go install go.octolab.org/toolset/maintainer@latest`, or a macOS or Linux archive (amd64 or arm64) from [GitHub Releases](https://github.com/octomation/maintainer/releases). The Homebrew Formula is deprecated on 2026-11-05; [Get started](/quickstart/) shows how to switch.

## Known limitations

- Contribution commands need a GitHub token, even for a public profile, and read only the token owner's calendar. They do not edit a repository or create contributions.
- The `suggest` schedule is fixed at 05:00–19:00 UTC.
- A snapshot covers one calendar year.
- A few days can read one lower than the profile page shows; contributions the token cannot see are the likely, unconfirmed cause ([issue #64](https://github.com/octomation/maintainer/issues/64)).
- `go vanity build` loops on a package path outside its module prefix instead of returning an error.
- `makefile build` has no include cycle detection ([issue #81](https://github.com/octomation/maintainer/issues/81)).
