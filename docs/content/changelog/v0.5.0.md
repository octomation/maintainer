# v0.5.0 — Less to carry.

Maintainer v0.5.0 narrows the tool to a contributor's daily work: `fetch` and `status` for your checkouts, the contribution commands for your GitHub calendar, and the local hub for the issues across your repositories. Two build helpers that served other jobs are gone. Configuration, state, pins, snapshots and the cache of fast repeat runs from v0.4.1 keep working.

## Breaking: two commands removed

- `maintainer go vanity build` is removed, and the `maintainer go` group with it. It wrote static pages for Go vanity import paths from `modules.yml`.
- `maintainer makefile build` is removed. It expanded the `include` lines of a Makefile into one self-contained file.
- A script that calls either command now fails with `unknown command`. If you still need one, keep v0.4.1 for it: the install script takes the tag, `sh -s -- -b ~/.local/bin v0.4.1`.

## Version output

- `maintainer version` prints `features    : -`. The `boilerplate` feature it listed as enabled did nothing and is gone.

## Known limitations

- A change that keeps the total of a month, such as one contribution removed and another added, is not seen until the folder of fast repeat runs is deleted.
- An issue opened in the browser near midnight keeps the browser's date on the profile, and the contribution commands may put it a day off.
- The contribution commands count by calendar year, not by the profile's rolling twelve months.

**Upgrade:** with Homebrew, run `brew update` followed by `brew upgrade --formula octolab/tap/maintainer`. With the install script, pass the tag: `sh -s -- -b ~/.local/bin v0.5.0`. With Go, run `go install go.octolab.org/toolset/maintainer@v0.5.0`. For a manual installation, use a [v0.5.0 release archive](https://github.com/octomation/maintainer/releases/tag/v0.5.0). Run `maintainer version` to check the installed version. If you use the agent skill, [replace it](/agents/#keep-it-in-step) with the new binary’s copy.
