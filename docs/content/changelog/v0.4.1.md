# v0.4.1 — Today counts in full.

Maintainer v0.4.1 makes `lookup`, `suggest`, `histogram`, `snapshot` and `diff` count all of today, as the contribution calendar on your GitHub profile does. Until now a pull request review made late in the UTC day could be missing until the next UTC day: GitHub ended today at midnight in the time zone of your account, so with an account in Tokyo the reviews after 15:00 UTC did not count, and repeat runs did not notice them. Configuration, state, pins, snapshots and the cache of fast repeat runs from v0.4.0 keep working.

## All of today

- A review counts on today from the next run, whatever time it is in your account's time zone, as on the profile.
- `suggest` sees all of today: a busy day is not taken for a quiet one, and the target of its week stays right.

[See how the days are counted →](/contributions/)

## Known limitations

- A change that keeps the total of a month, such as one contribution removed and another added, is not seen until the folder of fast repeat runs is deleted.
- An issue opened in the browser near midnight keeps the browser's date on the profile, and the commands may put it a day off.
- The commands count by calendar year, not by the profile's rolling twelve months.

**Upgrade:** with Homebrew, run `brew update` followed by `brew upgrade --formula octolab/tap/maintainer`. With the install script, pass the tag: `sh -s -- -b ~/.local/bin v0.4.1`. With Go, run `go install go.octolab.org/toolset/maintainer@v0.4.1`. For a manual installation, use a [v0.4.1 release archive](https://github.com/octomation/maintainer/releases/tag/v0.4.1). Run `maintainer version` to check the installed version. If you use the agent skill, [replace it](/agents/#keep-it-in-step) with the new binary’s copy.
