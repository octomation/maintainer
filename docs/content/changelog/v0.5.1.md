# v0.5.1 — Yours alone.

Maintainer v0.5.1 closes five ways in which another account of your computer, or a repository that you opened, could reach your GitHub token, your private issues or the layout of your checkouts. Three of the changes break a habit: the hub opens with `maintainer service open`, the `--token` flag is gone, and a `fetch.toml` or a `.env` in the working directory is no longer read.

## The hub is for your account only

- `maintainer service open` opens the hub in your browser. Each start of the service makes a new address that only your account can learn; `--print` prints it instead.
- The plain address `http://maintainer.localhost:17841/` and old bookmarks still load the pages, without data: the page says to run `maintainer service open`.
- If you are the only account of your computer, `access = "open"` in `service.toml` keeps the plain address, your bookmarks and open tabs working as before.
- Run it again after each start of the service: an upgrade, a reboot or `brew services restart octolab/tap/maintainer`.
- The service holds both loopback addresses of its port, `127.0.0.1` and `[::1]`. If another program holds one, the start fails and names it.
- The browser keeps only the theme, and the theme resets at each start. The open owners of the repository tree last while the page is open.
- `maintainer service open` also clears what earlier releases stored in the browser under `maintainer.localhost`. If you opened the hub through `localhost` or an IP address, open that address once after the upgrade.

[See how access works →](/service/#access)

## Breaking: `--token` is removed

- `maintainer fetch` and `maintainer github` no longer take `--token`: other accounts of a computer can read command lines. A run that passes the flag, or any argument that is `--token` or starts with `--token=`, stops with exit `2`; write a file of that name as `./--token…`.
- Set `GITHUB_TOKEN` in the environment. For `fetch`, a profile can also name its variable or file with `token_env` or `token_file`.

## Breaking: the working directory configures nothing

- `fetch`, its subcommands and `status` no longer read `./fetch.toml` or `./fetch.yaml`. A repository or an archive that ships such a file can no longer choose where `fetch --apply` clones.
- If you keep the file in a workspace folder, pass `--config ./fetch.toml`, set `MAINTAINER_FETCH_CONFIG`, or move it to `~/.config/maintainer/`. A run that finds only the file in the working directory stops with exit `2` and says so.
- `maintainer fetch config init` writes `~/.config/maintainer/fetch.toml` and prints the path.
- The hub no longer reads `fetch.toml` from your home folder: name it in `[fetch] config` of `service.toml` or move it to `~/.config/maintainer/`.
- The contribution commands no longer read a `.env` file: export `GITHUB_TOKEN`.

[See where the configuration comes from →](/fetch/#configuration)

## Known limitations

- The hub speaks plain HTTP. A program of another account that takes the port after the service stops sees the addresses that an open tab still requests. On a computer with other accounts, close the tabs of the hub before you stop the service.
- A change that keeps the total of a month, such as one contribution removed and another added, is not seen until the folder of fast repeat runs is deleted.
- An issue opened in the browser near midnight keeps the browser's date on the profile, and the contribution commands may put it a day off.
- The contribution commands count by calendar year, not by the profile's rolling twelve months.

**Upgrade:** with Homebrew, run `brew update` followed by `brew upgrade --formula octolab/tap/maintainer`, then `brew services restart octolab/tap/maintainer` and `maintainer service open`. With the install script, pass the tag: `sh -s -- -b ~/.local/bin v0.5.1`. With Go, run `go install go.octolab.org/toolset/maintainer@v0.5.1`. For a manual installation, use a [v0.5.1 release archive](https://github.com/octomation/maintainer/releases/tag/v0.5.1). Run `maintainer version` to check the installed version. If you use the agent skill, [replace it](/agents/#keep-it-in-step) with the new binary’s copy.
